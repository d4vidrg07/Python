# Python Portfolio

Python exercises and exam solutions from my Computer Engineering degree at ULPGC (University of Las Palmas de Gran Canaria). Everything here is organized by topic.

## Contents

| Folder | What it covers |
|---|---|
| [`linked-lists/`](linked-lists) | Linked list implementations (singly and doubly linked): a generic list with insertion at the start, end and any position, plus applications such as a browser history, a loan register, a music playlist and a task list. |
| [`oop/`](oop) | Object-oriented programming: classes, encapsulation with private attributes and properties, class attributes and relationships between classes (bank account, transport card, orders, playlists, student enrollment). |
| [`algorithms/`](algorithms) | Highlights from the Algorithms and Programming course: list and string exercises with their own READMEs and tests. |
| [`exams/`](exams) | Solutions to exam exercises: nested dictionaries ([`hardest-exam`](exams/hardest-exam)) and regular expressions with text file output ([`select-strs-regex`](exams/select-strs-regex)). |

## Skills shown

- **Data structures:** lists, dictionaries and linked lists (singly and doubly linked).
- **Algorithms:** list and string processing and the algorithmic exercises from the Algorithms and Programming course. Those live in their own repository: [Algorithms-and-Programming-](https://github.com/d4vidrg07/Algorithms-and-Programming-).
- **Object-oriented programming:** classes, encapsulation, class attributes and properties.
- **Text processing:** regular expressions and file reading and writing.

## Notes

- Some files contain only the classes I wrote. The base classes or helper modules they use (for example `ContainerBase` or the product and song classes) were provided by the course and are not included here.
- Exam exercises were solved by me; the statements and data formats come from the assignments.
- I also write the same kind of programs in Java: see [java-dsa](https://github.com/d4vidrg07/java-dsa).
