# Algorithms & Programming: Highlights

A selection of exercises from the **Algorithms and Programming** course (ULPGC) that I consider representative of my work. The code lives in its own repository, [Algorithms-and-Programming-](https://github.com/d4vidrg07/Algorithms-and-Programming-), and each exercise has a README with the problem, the approach, the complexity and how to run it.

## Python idioms and string/list processing

| Exercise | What it shows |
|---|---|
| [Order crossover](https://github.com/d4vidrg07/Algorithms-and-Programming-/tree/main/lists/order-crossover) | Genetic-algorithm operator: slicing, circular traversal and membership checks on lists. |
| [Calibration sum](https://github.com/d4vidrg07/Algorithms-and-Programming-/tree/main/strings/calibration-sum) | String parsing from both ends, edge cases and unit tests with `pytest`. |
| [`select_strs`](../exams/select-strs-regex) | Regular expressions and text file output (exam exercise). |
| [`get_hardest_exam`](../exams/hardest-exam) | Nested dictionaries and aggregation (exam exercise). |

More highlights (graph algorithms, backtracking and dynamic programming) will be added as I complete them.
